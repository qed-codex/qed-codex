About QED Codex

QED Codex brings credited informalizations by people and AI alongside the Lean source and dependency data. The front page lists the proofs in the directory.

Guide for AI agents

QED Codex does not verify proofs. Where a verification record exists for a proof, its page links to it.

Contributing and licenses

Sources, licences and import register

New text written or generated for QED Codex is CC BY 4.0. Previously published text shows its source licence. Imported text keeps its own licence, shown beside it. Code is MIT.

On a module, select “Add an informalization” to open a file on GitHub and propose it by pull request. The contribution guide explains attribution, licensing and how to flag a problem. Public submissions use CC BY 4.0. The directory code uses the MIT License. Permission-only text credits its writer, links the source and is excluded from the downloadable mirrors. Outside resources retain their authors’ terms.

Informalizations appear in ledger arrival order, oldest first.

The submitter is responsible for the statement and the right to publish it under the displayed licence. Maintainers may decline or remove any text and will remove it in good faith on a takedown request sent to {{email}} or when a problem is found.

Glossary

Import rank
Ranks reachable project modules by PageRank, the number of direct project dependents and the size of the cut. Rank 1 is highest.
Cut
The number of other project modules that become unreachable from Main when this module is removed from the original import graph.
Spine rank
Position on Rosetta’s 200-module review list. A dash means the module is outside that list.
Upstream
Whether the original file was retained or removed in the pinned upstream comparison. Mathlib files are outside the project.
The five yes/no badges
RH denotes the Riemann Hypothesis. Zeta zero, L nonvanishing, L zero and Primitive L zero denote the other four compiled targets. Yes means the declaration occurs in that target’s dependency closure. For a module, yes means at least one of its declarations occurs there.
Used by
The subset of those five theorems whose dependency closures include a declaration. A search of source mentions can miss a route that the compiled data records.

Featured elsewhere

  • Andrew O’Desky, Statements of the Lean RH project. Mathematical statements for the theorems and definitions of the proof, with written proofs for some principal results. Start with “Riemann hypothesis for Dirichlet L-functions” and “Zero-freeness for all Dirichlet characters”.
  • Bartosz Naskręcki, “How the announced proof of the Riemann hypothesis is put together”. An illustrated atlas and Lean blueprint: the argument mapped component by component, every step linked to pinned Lean source, with a record of what has been machine-checked.
  • Michael O. Rubinstein, “The Alpöge–Claude proof of the Riemann hypothesis explained for the Riemann zeta function”. A guide written by Claude Fable 5.2, Codex Astra 6.2 and Gemini Carbon at his request.
  • Jimmie Adriazola, “An End-to-End Reconstruction of the Alpöge–Claude Route to the Riemann Hypothesis”. A reconstruction of the argument in conventional mathematical language.
