# Copy descriptors for the packed demand words

Appendix E constructs the fields of a kernel before choosing wire bits. For
an AB demand, intersecting the old and new intervals in the concatenated
bundle gives three integers: a source offset, a destination offset and a
length. The results below identify these descriptors with the exact bit
bijection used in the coefficient identity.


### `fieldStart`

 Starting position of a field in an ordered concatenation. 

### `orderedBits_offset`

 Ordered concatenation preserves the position within each field. 

### `CopySlice`

 The contiguous piece copied from one old field into one demand field. 

### `CopySlice.sourceOffset`

 Starting bit offset within the source field for this copy. 

### `CopySlice.targetOffset`

 Starting bit offset within the target field for the same copied interval. 

### `CopySlice.length`

 Number of consecutive bits copied from the source offset to the target offset. 

### `copySlice`

 The shared interval starts at the larger start and ends at the smaller
end. Truncated subtraction gives length zero for disjoint or empty fields. 

### `demandSlice`

 Descriptor generated by one old field and one new piece of a bundle.
It depends only on the two lists of widths and their combinatorial orders. 

### `demandBitEquiv_eq_iff_slice`

 The bit bijection sends a new bit to an old bit precisely when the single
copy descriptor for that pair of fields contains both local positions.
