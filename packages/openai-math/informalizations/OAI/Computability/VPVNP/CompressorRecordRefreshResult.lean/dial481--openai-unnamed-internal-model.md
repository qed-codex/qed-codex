# Correctness of all native degree-refresh branches

Determinism transfers the verified memory contents and resource bound to every complete
execution. Starting from the old incidence directory, an arbitrary family of block tapes
passes the physical preparation and term checks exactly when it encodes a unique admitted
branch that extends to a complete native refresh.


### `Run.result`

 Every successful full execution has the selected incidence columns, local-history
fields, interval frame and a linear bound on its total calls plus probes. 

### `bundle_total_le_max`

 Each bundle contains one old width for every port, even when several widths vanish. 

### `branches_iff`

 Equivalence between acceptance of arbitrary physical block tapes and unique complete
branch realizability. The prepared demand memory is generated by executing the prefix.
