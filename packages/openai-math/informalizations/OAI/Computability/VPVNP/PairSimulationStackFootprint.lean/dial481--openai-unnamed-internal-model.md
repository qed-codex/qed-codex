# Exact private writes of a stack nomination

Popping a bit moves the top pointer and leaves its private cell intact. A
later push can overwrite that same cell. The virtual leaf therefore keeps
the entire ordered list of private writes, even when the final logical
stack is empty. This list and the native tick/choice trace depend only on
the source stack execution.


### `Footprint`

 A stack execution's chronological native events and private cell writes, including pushes
whose cells may subsequently be popped or overwritten. 

### `Footprint.events`

 The native ticks and choice events generated by the bounded stack execution, in execution
  order. 

### `Footprint.writes`

 The sequence of private address and value pairs written by pushes, in the order they
  update memory. 

### `Footprint.applyWrites`

 The machine's private cells after all pushes, in chronological order. 

### `Footprint.applyWrites_congr`

 The updated cell depends only on the same input cell and the sequence
of pushes. In particular a caller can apply the footprint to its scratch
subarray without looking at the memory below it. 

### `Footprint.prepend`

 Prefix the tail footprint with the earlier instruction's events and writes, preserving
chronological order in both lists. 

### `footprint`

 Compute the native trace and private write list during bounded source
interpretation. On a short choice stream the three padding ticks precede
the missing choice. 

### `footprint_probes`

 The stack instructions only touch private cells on every execution,
including unfinished and rejected prefixes. 

### `footprint_parse`

 The native choice events are exactly the consumed prefix, and every
continuing instruction has four transitions, followed by the halt jump. 

### `footprint_append`

 The native code does not inspect extra source bits after an accepted
halt. The chronological writes also stay fixed under extension. 

### `footprint_native`

 Realize the computed tick/choice trace and the entire final private
memory, including overwritten or stale cells. The prefix theorem allows
any continuation and external memory.
