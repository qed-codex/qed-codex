# Charges on the terminal trace reached from the detailed descriptor boundary

The bootstrap, prefix and traversal reports are taken from the same accepted
terminal trace. Their bounds use the fixed bootstrap table and record limit,
even when the selected calendar length and its resident directories vary.


### `eventually_packed_prefix_costs`

 At a threshold fixed before the scalar assignment and the descriptor path,
each accepted terminal trace has its charged prefix on the physical memory at
the end of that path. The worker code is the fixed allocation-shape bank.
