# Deterministic subexponential algorithms for bounded-width SAT

`SubexponentialSAT.SubexpOrderedRawMainTheorem.mainTheorem_explicit` is the
formalized main theorem of *A Subexponential Algorithm for Bounded-Width SAT*.
`SubexponentialSAT.SqrtLogSpace.exact_count_and_sat` strengthens the subsequent
square-root-logarithmic result with exact counting and a polynomial bound on
all-prefix visited-tape space.
