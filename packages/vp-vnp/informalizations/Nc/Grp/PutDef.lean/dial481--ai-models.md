# Writing units: definitions


### `padTake`

 The first `ub` bits, filled with zeros. 

### `putL`

 Write the units of a string (with its final 1) at the keys; fail if the number of keys is wrong. 

### `putAll`

 Write contents at keys. 

### `putsL`

 Write several strings.
