# Codes of finite types


### `bitsN`

 The first `L` binary digits. 

### `exists_code`

 A finite type has a code of fixed length. 

### `val_bitsN`

 The value of the binary digits (lowest first). 

### `nmEquiv`

 Names as a sum of types. 

### `Nm.instFintype`

 Names form a finite type.
