# Walks in a tower


### `nodeAt`

 The chamber after `s` steps. 

### `path`

 The path from `c` to `c'` by way of `γ`. 

### `pl`

 The number of steps until the end is reached for the first time. 

### `pn`

 The chamber after `s` steps. 

### `exists_edge`

 The edge of step `s`.
